What is a Nano ID?

Nano ID is a compact identifier format designed to create random strings that work well in URLs. A common configuration uses 21 characters from a URL-safe alphabet, but the suitable length depends on your collision-risk tolerance and application requirements.

Nano ID vs UUID

A default Nano ID is shorter than a standard 36-character UUID and is convenient for URLs and compact keys. UUIDs have a standardized 128-bit structure and version conventions. Choose a format supported by the systems that will store or consume the identifiers.

Frequently asked questions

Can I choose the Nano ID length?

Yes. Choose from 1 to 64 characters. Longer IDs provide more possible combinations; very short IDs have a higher chance of collisions, especially when generating many values.

Can I export IDs to Excel?
