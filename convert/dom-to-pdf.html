Save a web page or HTML document as a PDF

When you need a shareable copy of a web page, report, invoice, or locally saved HTML document, PDF is often easier to send and print than a live page. Add the HTML source, review the rendered preview, and adjust the available page settings before generating the PDF.

A practical way to use this page

  1. Paste HTML or select a supported local HTML file, depending on the input option you want to use.
  2. Review the preview. Check images, fonts, tables, page width, and any content that depends on external resources.
  3. Choose the available page and rendering settings, generate the PDF, then open it and inspect page breaks before sharing.

The preview is important

A browser page can reflow depending on screen width, loaded fonts, images, and CSS. Content that looks correct in a narrow preview may be too wide for a printed page, while long tables or large images may cross page boundaries. Check the preview at the intended page size and inspect the final PDF.

Not every website can be reproduced exactly as a PDF. Content that requires a login, scripts, external network resources, or browser-specific behaviour may not render as expected. Keep a copy of the source HTML, and do not assume the generated PDF includes content that was not visible in the preview.

Frequently asked questions

Should I keep the original file?

Yes. Keep the source until you have checked the generated result and confirmed it works for the intended task.

Does conversion guarantee the result will work everywhere?

No. Receiving applications can have different format, size, and layout requirements. Review the output and test it in the destination workflow before relying on it.
