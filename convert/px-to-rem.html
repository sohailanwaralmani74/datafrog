How to convert px to rem and rem to px

With a root font size of 16px, divide a pixel value by 16 to get rem. For example, 8px ÷ 16 = 0.5rem. To convert in the other direction, multiply the rem value by the root font size: 1rem × 16 = 16px. If your project uses a different root font size, change the setting in the converter and the results will update.

rem = px ÷ root font size
px = rem × root font size

Why use rem units in CSS?

Rem units are relative to the root element's font size, which can make typography and spacing scale consistently when that base size changes. Pixel units can still be useful for fixed details such as thin borders. Check the root font size used by your project before relying on a conversion table, because a custom root size changes every px-to-rem and rem-to-px result.
