Choose the worksheet layout that suits your data

JSON can contain objects inside objects and lists inside records. A spreadsheet is a grid, so the best layout depends on what you need to do with the data after conversion.

Flatten nested JSON into one worksheet

This layout keeps each top-level record on one row. Nested object fields become columns with dotted names, such as customer.name and customer.city. It is convenient for filtering and quick review. Arrays stay in a cell as JSON text because spreading a list across columns can make rows difficult to compare.

Put nested objects and arrays in separate worksheets

This layout creates a main worksheet for top-level records and additional worksheets for nested objects or arrays. Each related worksheet includes a _parent_id column so you can identify which main record it belongs to. Array rows also include an item index. This is usually easier to work with when a record contains multiple items or other repeated entries.

Check the workbook before using it

  • Make sure the JSON is valid and the top-level value is an object or an array of records.
  • Review blank values, long text, dates, and identifiers that may look like numbers but should remain text.
  • In separate-worksheet mode, use the parent IDs to connect related records. A workbook is not the same as a database, and relationships are represented by these ID columns.

Conversion runs locally in your browser. The workbook contains the data structure created by this converter; it does not recreate application behavior or guarantee that every destination system will interpret values in the same way.
