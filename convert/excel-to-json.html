Excel to JSON Converter Reference

The Excel to JSON converter bridges the gap between tabular spreadsheets and JavaScript Object Notation (JSON). When building modern web applications, loading fixtures into MongoDB or PostgreSQL JSONB columns, or preparing mock data for frontend testing, converting Excel sheets into structured JSON objects eliminates manual data reformatting and schema mismatches.

Output Structure & Header Mapping

When the "First row as JSON keys" option is enabled, the converter treats row 1 as property identifiers. Each subsequent row generates an individual JSON object where column names serve as keys: 

[
  { "id": 1, "name": "Acme Corp", "balance": 1420.50, "active": true },
  { "id": 2, "name": "Globex", "balance": 890.00, "active": false }
]

If the header option is unchecked, the converter outputs a 2D array of raw values ([["id", "name"], [1, "Acme Corp"]]), preserving the exact coordinate layout of the sheet.

Data Type Inference

  • Numeric Fields: Integer and floating-point quantities are serialized as unquoted JSON numbers (e.g. 42, 19.99).
  • Boolean Tokens: Cell values containing TRUE or FALSE are parsed as native JavaScript booleans.
  • Empty & Blank Cells: Blank cells within a row are emitted as null or omitted according to sparse array rules.
  • Date & Time Values: Excel serial date timestamps are converted to standardized ISO 8601 strings (YYYY-MM-DD).

Frequently Asked Questions

Can I convert workbooks containing multiple sheets?

Yes. The workbook metadata inspector reads all worksheet tabs in the file. Use the "Worksheet" dropdown to switch between tabs and convert any sheet independently.

Can I edit cell values prior to downloading JSON?

Yes. The data preview table is content-editable. Click any cell to modify values, fix typos, or adjust column names before clicking Convert to JSON.

Is there a file size limit for in-browser JSON conversion?

Because parsing runs client-side using SheetJS in browser RAM, files with tens of thousands of rows process in seconds without encountering server upload size caps or timeouts.
