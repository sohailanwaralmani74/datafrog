Turn workbook rows into JSON your workflow can use

When an Excel workbook needs to feed another tool, you may need its rows as structured JSON rather than a spreadsheet. Use this page to choose the workbook, review the worksheet data, adjust the preview if needed, and generate JSON for an import or data exchange.

A practical way to use this page

  1. Choose the Excel workbook and select the worksheet you need. Do not assume every workbook's relevant data is on its first sheet.
  2. Review the editable preview and confirm the column headings. The headings may become the property names in each JSON object.
  3. Generate the JSON, inspect a few objects, then copy or download the result.

Check the shape before you send it

A worksheet is a grid, while JSON can represent objects and arrays. The selected worksheet and its headings affect how the output is structured. Check blank or repeated headings, empty cells, and identifiers with leading zeroes. If a workbook contains several sheets, verify that you converted the intended one.

The output represents worksheet data; it should not be treated as a complete copy of an Excel workbook. Spreadsheet formatting, formulas, charts, macros, and workbook relationships may not be represented in JSON. Keep the original workbook and confirm that the receiving application expects the generated structure.

Frequently asked questions

Should I keep the original file?

Yes. Keep the source until you have reviewed the generated result and confirmed that it meets the needs of the next step in your workflow.

Does a successful conversion guarantee the output is correct for my use?

No. Check the output against your requirements and test it in the application that will receive it, especially when structure or data types matter.
