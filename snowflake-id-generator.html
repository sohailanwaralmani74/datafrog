What is a Snowflake ID?

A Snowflake-style ID is a 64-bit integer assembled from a timestamp, a machine or worker identifier, and a per-millisecond sequence. The timestamp helps IDs sort roughly by creation time, while worker and sequence fields allow many IDs to be produced without relying on a central database.

Avoiding duplicate IDs

This page generates IDs locally using the worker and datacenter values you choose. For use across multiple machines, assign each active generator a unique combination and ensure their clocks are managed correctly. Reusing the same combination across independent generators can create collisions.

Frequently asked questions

Are Snowflake IDs UUIDs?

No. A Snowflake ID is typically a 64-bit integer, while a UUID is a 128-bit identifier commonly displayed as a 36-character string.

Can I export a batch?

Yes. Generate up to 500 IDs and copy them or export them as CSV or an Excel workbook. Generation takes place in your browser; Excel export loads its spreadsheet library only when requested.
