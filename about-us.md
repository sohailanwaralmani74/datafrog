  <section style="margin-bottom: 2rem;">
    <h2 style="font-size: 1.5rem; font-weight: 600; margin-bottom: 1rem; color: var(--text-primary);">What DataFrog is for</h2>
    <p>DataFrog brings together small utilities for common data tasks: opening a file to understand its structure, checking whether its syntax is valid, comparing two versions, examining columns and values, and converting data between supported formats. The goal is to help people complete a specific task without installing a separate desktop application for every format.</p>
    <p>Many tools are designed to process the input in the browser rather than send the file to a DataFrog processing server. Check the individual tool's instructions and limitations before using it with important data. Browser-side file processing does not mean that the website makes no network requests: the site may load third-party analytics or advertising resources.</p>
  </section>

  <section style="margin-bottom: 2rem;">
    <h2 style="font-size: 1.5rem; font-weight: 600; margin-bottom: 1rem; color: var(--text-primary);">How we approach tool content</h2>
    <p>Each tool should explain the task it supports, the input it accepts, the output it produces, and limitations that could affect the result. For conversions, users should check the output rather than assume that a successful download guarantees a perfect conversion. Nested data, unusual encodings, malformed files, very large inputs, and differences between file formats can change what a tool can reliably do.</p>
    <p>We aim to improve pages from the behaviour of the actual tool, not by repeating generic feature claims. Where a limitation or compatibility detail matters, it should be stated plainly.</p>
  </section>
