Frequently Asked Questions

Is my Excel file safe when using this Excel Viewer?

Yes, 100%. Your Excel file (.xlsx, .xls, .xlsm) is parsed and rendered entirely inside your web browser's local memory using client-side JavaScript. Zero data or files are uploaded to any external server.

Which Excel file formats are supported?

The tool supports .xlsx, .xls, .xlsm, .csv, and .tsv spreadsheet formats.

Can I switch between multiple worksheets?

Yes! The workbook sheet tabs appear at the top of the table, allowing you to seamlessly switch between worksheets.

Can I view cell formulas and export data?

Yes, click Show Formulas to toggle cell formulas, or click Export Sheet as CSV to download active worksheet data.
