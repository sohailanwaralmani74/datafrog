Frequently Asked Questions

How does Excel Compare compare multi-sheet workbooks?

The Excel Compare tool inspects worksheet names, active sheets, used cell ranges, cell values, and formula strings, generating a sheet-by-sheet comparison audit.

Are my Excel workbooks uploaded to any server?

No, 100% private. SheetJS parses binary `.xlsx` and `.xls` files directly inside local browser RAM memory. Zero spreadsheet data is uploaded.

Which Excel file formats are supported?

The tool supports `.xlsx`, `.xls`, `.xlsm`, and `.csv` spreadsheet files.
