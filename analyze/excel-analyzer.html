Excel Analyzer Features

Complete workbook statistics, formula audits, and multi-sheet profiling

📑 Multi-Worksheet Profiling

Audits all visible and hidden sheets within a workbook, comparing row counts, cell counts, and formulas.

🧮 Formula & Error Audit

Tracks formula counts and highlights broken formula references (`#N/A`, `#REF!`, `#VALUE!`, `#DIV/0!`).

📌 Merged Cell & Structure Detector

Detects merged cell ranges (`!merges`) across sheets that may impair data export or pivot table creation.

📊 Cell Data Type Breakdown

Provides visual distribution progress bars for text, numeric, formula, boolean/date, and blank cells.

📋 Executive Summary Export

🔒 100% Client-Side Privacy

Frequently Asked Questions

Is my Excel workbook safe during analysis?

Yes, 100%. Your Excel file (.xlsx, .xls, .xlsm) is parsed, profiled, and audited entirely inside your web browser's local memory using client-side JavaScript. Zero data or files are uploaded to any external server.

Which workbook metrics are audited by the Excel Analyzer?

The tool audits total worksheets, visible vs hidden sheets, row and column counts per sheet, formula counts, formula error detection (#N/A, #REF!), cell data type distribution, merged cells, and missing value ratios.

Which Excel file formats are supported?

The tool supports .xlsx, .xls, .xlsm, and .csv spreadsheet formats.

Can I export the workbook analysis report?

Yes! You can copy the generated text report, download the executive summary file, or click Export Stats CSV to save worksheet and column statistics as a CSV file.
