Frequently Asked Questions

Which JSON Schema specifications are supported?

The JSON Schema Validator supports Draft-04, Draft-06, Draft-07, Draft 2019-09, and Draft 2020-12 JSON Schema specifications.

Is my JSON payload or schema uploaded to any server?

No, 100% private. Both your JSON data payload and your JSON Schema definition are validated entirely inside your local web browser's RAM memory using client-side JavaScript.

What validation errors are caught by the schema engine?

The validator checks missing required properties, data type mismatches, enum value constraints, string patterns (regex), numeric min/max limits, array item counts, and additional properties.
