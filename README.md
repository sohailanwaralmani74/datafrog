# DataFrog.tools — Browser-Based Data Intelligence Workspace

Welcome to **[DataFrog.tools](https://datafrog.tools/)** — a privacy-first, browser-based data intelligence workspace for developers, data engineers, and analysts. DataFrog provides 25 specialized utilities across 5 core categories (**Inspect**, **Analyze**, **Validate**, **Compare**, and **Visualize**).

All tools execute 100% locally inside your browser memory — **zero server uploads, zero API calls, zero tracking, and fully offline-capable once loaded**.

---

## 🌐 5 Core Tool Categories (25 Tools)

### 🔍 Inspect Tools
Explore raw structures, nested paths, and document hierarchies interactively:
- [JSON Viewer](https://datafrog.tools/inspect/json-viewer/) — Interactive tree viewer, node depth metrics, and JSON path copy.
- [CSV Viewer](https://datafrog.tools/inspect/csv-viewer/) — Tabular data grid viewer with auto delimiter detection and column metrics.
- [XML Viewer](https://datafrog.tools/inspect/xml-viewer/) — XML element hierarchy tree viewer, XPath finder, and attribute inspector.
- [YAML Viewer](https://datafrog.tools/inspect/yaml-viewer/) — Interactive YAML tree parser, node path finder, and depth statistics.
- [Excel Viewer](https://datafrog.tools/inspect/excel-viewer/) — Multi-sheet workbook spreadsheet viewer (.xlsx, .xls, .xlsm) with sorting and formula toggles.

### 📊 Analyze Tools
Generate statistical summaries, field frequency profiles, and quality reports:
- [JSON Analyzer](https://datafrog.tools/analyze/json-analyzer/) — JSON complexity metrics, data type distribution, key frequencies, and structural audits.
- [CSV Analyzer](https://datafrog.tools/analyze/csv-analyzer/) — Column profiling, numeric summary stats (mean, median, min, max, sum), missing value detection, and duplicate checks.
- [Excel Analyzer](https://datafrog.tools/analyze/excel-analyzer/) — Multi-sheet workbook statistics, formula audits, cell type breakdowns, and data health scores.
- [XML Analyzer](https://datafrog.tools/analyze/xml-analyzer/) — XML hierarchy depth analysis, element frequency distributions, and namespace usage reports.
- [Log Analyzer](https://datafrog.tools/analyze/log-analyzer/) — Nginx, Apache, IIS, and app log analysis with level breakdowns, HTTP status codes, and IP profiling.

### ✅ Validate Tools
Enforce syntax compliance, line & column error pointers, and schema constraints:
- [JSON Validator](https://datafrog.tools/validate/json-validator/) — JSON syntax validator with exact line/column error highlights, pretty-printing, and minification.
- [XML Validator](https://datafrog.tools/validate/xml-validator/) — XML syntax & malformed tag validator with namespace checking and formatting.
- [CSV Validator](https://datafrog.tools/validate/csv-validator/) — CSV column consistency checker, duplicate header detector, and quote escaping auditor.
- [YAML Validator](https://datafrog.tools/validate/yaml-validator/) — YAML syntax & indentation validator with anchor and mapping structural checks.
- [JSON Schema Validator](https://datafrog.tools/validate/json-schema-validator/) — JSON Schema validator supporting Draft-04, Draft-07, and Draft 2020-12 with property path error reports.

### ⚖️ Compare Tools
Side-by-side and inline structural diffing engines:
- [Text Compare](https://datafrog.tools/compare/text-compare/) — Line & word diff engine with side-by-side / inline views and whitespace toggles.
- [JSON Compare](https://datafrog.tools/compare/json-compare/) — Structural object tree diffing, key order normalization, added/removed key detection, and JSON path pointers.
- [CSV Compare](https://datafrog.tools/compare/csv-compare/) — Tabular row alignment diff engine with delimiter auto-detection and cell modification highlights.
- [XML Compare](https://datafrog.tools/compare/xml-compare/) — DOM element tree comparator evaluating tags, attribute key-values, namespace URIs, and XPath locations.
- [Excel Compare](https://datafrog.tools/compare/excel-compare/) — Multi-sheet workbook diff engine auditing worksheet tabs, row values, and formula changes.

### 📈 Visualize Tools
Transform raw structured data into interactive diagrams, dashboards, and charts:
- [JSON Visualizer](https://datafrog.tools/visualize/json-visualizer/) — Interactive visual tree builder with branch expansion, node search, and JSON path tracing.
- [CSV Visualizer](https://datafrog.tools/visualize/csv-visualizer/) — Convert CSV datasets into responsive Bar, Line, Pie, and Doughnut charts with PNG export.
- [XML Visualizer](https://datafrog.tools/visualize/xml-visualizer/) — Interactive DOM element hierarchy viewer with XPath copying and attribute badges.
- [Excel Visualizer](https://datafrog.tools/visualize/excel-visualizer/) — Multi-sheet workbook visualizer with searchable data tables and Chart.js dashboards.
- [YAML Visualizer](https://datafrog.tools/visualize/yaml-visualizer/) — Interactive YAML configuration tree view with key/value search and indentation mapping.
