About UUID versions

A UUID is a 128-bit identifier commonly used for database records, application objects, sessions, and distributed systems. Different versions create identifiers in different ways.

  • UUID v4: random or pseudorandom bits; a practical default for most applications.
  • UUID v7: includes a Unix timestamp and random bits, so identifiers sort roughly by creation time.
  • UUID v1 and v6: time-based formats; v6 rearranges timestamp fields for improved sorting.
  • UUID v3 and v5: deterministic identifiers derived from a namespace and name; v3 uses MD5 and v5 uses SHA-1.
  • UUID v2: a legacy DCE Security format and rarely needed in modern applications.
  • UUID v8: for application-specific formats; uniqueness depends on the implementation.

Frequently asked questions

Which UUID version should I use?

Use version 4 as a general-purpose random identifier. Consider version 7 when time ordering is useful and your systems support it. Use versions 3 or 5 when the same name and namespace must always produce the same identifier.

Can I generate multiple UUIDs?

Yes. Select a version and press Generate UUID again to create another identifier. Copy UUID places the displayed value on your clipboard.

Is my input sent to a server?

UUID generation and name hashing run in your browser. The name you enter for versions 3 and 5 is not sent to a DataFrog processing server.
